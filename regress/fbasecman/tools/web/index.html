fbasecman 回归测试平台使用说明

        
      

      

        
💡 操作指引

        
    
          
  • 树状分类展开：点击任一测试组标题（如 high_availability），即可展开查看包含的全部用例。
    • 
          
  • 整组执行：点击分类右侧的 [▶ 执行整组]，系统将在后台依次执行该类别下的全部测试。
    • 
          
  • 单用例执行：直接点击用例条目右侧的 [▶ 执行] 按钮，立即运行该单项。
    • 
          
  • 查看测试报告：测试执行完成后，条目右侧可点击 [📄 查看报告] 打开沉浸式弹窗，交互式查看执行步骤、中间状态表格、断言和完整日志。
    • 
          
  • 实时终端：下方停靠的终端抽屉可实时展示执行 stdout/stderr 日志，支持随时手动 [⏹ 终止执行]。
    • 
        

        
⚡ 命令行等效用法

        
./run.sh run high_availability.core_13_monitor_confirm

./run.sh run failed
